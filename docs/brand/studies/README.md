# Original vector studies

`installation-studies.svg` is a six-composition contact sheet. All letters, including
captions, are CoreText outlines from the bundled official Fraunces and Manrope
fonts. It contains no external bitmap dependencies or AI imagery. Open the SVG at
its full 1920 × 1340 aspect ratio; Quick Look may crop its square thumbnail.

The studies establish hierarchy and placement. The shared native implementation
uses the same typefaces and palette, with cached paths and bounded Canvas layers.
